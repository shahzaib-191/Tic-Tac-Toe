# Tic-Tac-Toe Game

A simple Tic-Tac-Toe game built using Python and Streamlit with Pygame for sound effects.

# Features

Two-player Tic-Tac-Toe game

Sound effects for moves, wins, and restarts

Interactive and easy-to-use UI

# **Technologies** 

✅ Python – Core programming language for game logic
✅ Streamlit – To create a web-based UI for the game
✅ Pygame – For handling sounds and game interactions
✅ TensorFlow Lite – Possibly for AI-based opponent or other ML-related tasks

## Installation

# Prerequisites

Ensure you have Python installed (recommended version: 3.10+).

Clone the Repository

git clone https://github.com/yourusername/Tic-Tac-Toe-Game.git
cd Tic-Tac-Toe-Game

Install Dependencies

pip install -r requirements.txt

Running the Game

streamlit run tic_tac_toe.py

After running the command, open the local URL displayed in the terminal.
